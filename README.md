# Season Islands Support

Season Islands için Türkçe ve İngilizce destek ve gizlilik sayfaları.

- `index.html` — destek ve gizlilik bağlantıları
- `privacy-tr.html` — Türkçe gizlilik politikası
- `privacy-en.html` — İngilizce gizlilik politikası

GitHub Pages için **Settings → Pages → Deploy from a branch → main → /(root)** seçilir. Bir derleme komutu ya da erişim anahtarı gerekmez.

Gizlilik metni değiştiğinde Türkçe ve İngilizce sayfaları aynı tarihle güncelle.
